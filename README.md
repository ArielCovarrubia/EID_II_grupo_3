# EID II - MATE1133

Proyecto colaborativo para la Evaluación Integrada de Desempeño N°2.

## Estructura

- `parte1_datos.py`: probabilidades, sumas parciales y límites.
- `parte2_graficos.py`: generación de los gráficos con `matplotlib`.
- `main.py`: integración, tablas, convergencia y recomendación.

## Instalación

```powershell
python -m pip install -r requirements.txt
```

## Ejecución

```powershell
python main.py
```

El programa solicita los primeros 8 dígitos del RUT utilizado para calcular
`p1`, `p2` y `p3`.

## Flujo de trabajo

- Integrante 1: rama `integrante-1`, solo `parte1_datos.py`.
- Integrante 2: rama `integrante-2`, solo `parte2_graficos.py`.
- Integrante 3: rama `main`, integración y revisión de Pull Requests.
